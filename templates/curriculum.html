🖥️ หมวดวิทยาการคอมพิวเตอร์หลัก (Core CS)

เน้นการปูพื้นฐานทฤษฎีทางคอมพิวเตอร์ โครงสร้างระบบ การเขียนโปรแกรม และความมั่นคงปลอดภัยไซเบอร์ เพื่อสร้างนักคอมพิวเตอร์ที่รอบรู้และพร้อมต่อยอดทุกเทคโนโลยี

🌐
โครงข่ายคอมพิวเตอร์
(Computer Networks)
เรียนรู้เกี่ยวกับการออกแบบ ติดตั้ง และบำรุงรักษาระบบเครือข่ายคอมพิวเตอร์ ทั้งแบบสายและไร้สายเพื่อการสื่อสารในองค์กร
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ
🛡️
ความปลอดภัยของข้อมูล
(Information Security)
เรียนรู้เกี่ยวกับการป้องกันและควบคุมความปลอดภัยของข้อมูลในระบบคอมพิวเตอร์ การเข้ารหัสลับ และการตรวจจับผู้บุกรุก
3 หน่วยกิต
🔍
ภูมิคุ้มกันและความเสียหายคอมพิวเตอร์
(Computer Forensics)
เรียนรู้เกี่ยวกับการตรวจสอบและวิเคราะห์ข้อมูลที่ถูกโจมตีทางไซเบอร์ การสืบค้นพยานหลักฐานดิจิทัล และกฎหมายคอมพิวเตอร์
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ
🗄️
การออกแบบระบบฐานข้อมูล
(Database Systems)
เรียนรู้เกี่ยวกับการออกแบบ ติดตั้ง และบำรุงรักษาระบบฐานข้อมูล รวมถึงเรียนรู้ SQL ซึ่งเป็นภาษาคิวรีสำหรับฐานข้อมูล
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ

</> หมวดเทคโนโลยีซอฟต์แวร์ (Software Tech)

เน้นการพัฒนาโปรแกรมประยุกต์ การวิเคราะห์ความต้องการ ระบบสารสนเทศขนาดใหญ่ ตลอดจนการจัดการโครงการซอฟต์แวร์ตามมาตรฐานสากลเพื่อรองรับตลาดแรงงานดิจิทัล

📦
การสร้างซอฟต์แวร์
(Software Engineering)
เรียนรู้เกี่ยวกับกระบวนการสร้างซอฟต์แวร์ การวิเคราะห์และออกแบบระบบ การทดสอบซอฟต์แวร์อย่างเป็นระบบและการบำรุงรักษา
3 หน่วยกิต
💻
การพัฒนาเว็บแอปพลิเคชันสมัยใหม่
(Modern Web App)
การเรียนรู้เชิงปฏิบัติด้วยการเขียนโปรแกรมฝั่งไคลเอนต์และเซิร์ฟเวอร์โดยใช้เฟรมเวิร์กยอดนิยม เช่น React, Next.js และ Node.js
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ
🖼️
การประมวลผลภาพดิจิทัล
(Image Processing)
เรียนรู้เกี่ยวกับการประมวลผลภาพดิจิทัลและวิเคราะห์ภาพ เช่น การปรับแต่งภาพ การค้นหาวัตถุ และการสกัดคุณลักษณะจากภาพ
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ
🗺️
ระบบสารสนเทศภูมิศาสตร์
(GIS Technology)
เรียนรู้เกี่ยวกับการประยุกต์ใช้เทคโนโลยีสารสนเทศในการวิเคราะห์ แสดงผลข้อมูล และแผนที่ทางภูมิศาสตร์ขั้นสูง
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ

🤖 หมวดปัญญาประดิษฐ์และวิทยาการข้อมูล (AI & Data Science)

ยกระดับสู่ความเชี่ยวชาญระดับแนวหน้า ระบบวิเคราะห์บิ๊กดาต้า การพยากรณ์เชิงสถิติ และการสร้างโมเดล Machine/Deep Learning สำหรับนวัตกรรมแห่งอนาคต

🧠
ภูมิปัญญาประดิษฐ์
(Artificial Intelligence)
เรียนรู้เกี่ยวกับการพัฒนาโปรแกรมและเทคโนโลยีที่ใช้ในการจำลองความเป็นมนุษย์ของระบบคอมพิวเตอร์ เช่น การประมวลผลภาษาธรรมชาติ
3 หน่วยกิต
📊
วิทยาการข้อมูล
(Data Science)
เรียนรู้เกี่ยวกับการทำงานกับข้อมูลขนาดใหญ่ การวิเคราะห์แสดงผลข้อมูลเชิงลึก และการประยุกต์ใช้เทคโนโลยีในเชิงธุรกิจ
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ
⚙️
การเรียนรู้ของเครื่อง
(Machine Learning)
การสร้างและประเมินประสิทธิภาพของโมเดลการเรียนรู้ เช่น Supervised และ Unsupervised Learning เพื่อการพยากรณ์ข้อมูล
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ
⌨️
การเขียนโปรแกรมสำหรับ Data Science
ปฏิบัติการเขียนโค้ดด้วยภาษา Python และ R เพื่อการสกัด ดึงข้อมูล จัดการโครงสร้างข้อมูล และทำ Data Cleansing ขั้นสูง
3 หน่วยกิต 🔬 มีห้องแล็บปฏิบัติการ
